## Method

Six workers, one per module group (same shape as the sweep), each
formalizing its entries from the sweep report and then checking the
trigger against the live repo on 2026-11-14 via the GitHub connector
(file contents, commit lists, repository search) and, where the
connector rate-limited, via public git protocol and web search.
Licences were verified from the repo's own LICENSE file text, never
from a badge, README claim, or GitHub metadata field — the same rule
as the sweep. The coordinator verified a sample of every worker's
claims itself and closed every gap the rate limit left (see
"Rate-limit episode" below). The per-group working files are kept as
evidence in `sweep/recheck-group-a.json` … `sweep/recheck-group-f.json`.
